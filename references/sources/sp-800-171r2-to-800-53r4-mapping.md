# SP 800-171 Rev 2 → SP 800-53 Rev 4 Parent-Control Mapping (DEFAULT track)

**What this is.** For each of the 110 CUI security requirements in NIST SP 800-171 Rev 2, the NIST SP 800-53 **Rev 4** control(s) and enhancement(s) NIST identifies as its source. This is the **default** mapping for CMMC Level 2 work. Look the requirement up here, then read the control text in `references/sources/sp-800-53-rev4-cui-parents.md`. Method and worked examples: `references/control-lineage.md`.

**Source.** NIST SP 800-171 Rev 2, **Appendix D, Tables D-1 through D-14**, transcribed verbatim from the government PDF (NIST.SP.800-171r2, updated Jan 28, 2021). The secondary ISO/IEC 27001 column in those tables is omitted here. Per Appendix D footnote 31 the controls are **taken from SP 800-53 Revision 4**.

**How NIST frames this mapping — quote this when a client leans on it too hard:**

> "Tables D-1 through D-14 provide a mapping of the basic and derived security requirements to the security controls in [SP 800-53]. The mapping tables are included for informational purposes and are not intended to convey or impart any additional security requirements beyond those requirements defined in Chapter Three. … satisfaction of a basic or derived requirement does *not* imply the corresponding NIST security control or control enhancement [in SP 800-53] has also been satisfied, since certain elements of the control or control enhancement that are not essential to protecting the confidentiality of CUI are not reflected in those requirements."

**Reading the tables.** Where NIST grouped several requirements in one row (e.g. 3.1.1 and 3.1.2 together), the mapped controls apply to every requirement in that group; those are shown here on one line.

**Secondary lens.** For the SP 800-171 Rev 3 → SP 800-53 Rev 5 view of the same requirements, see `references/sources/sp-800-171r3-to-800-53r5-mapping.md`.
