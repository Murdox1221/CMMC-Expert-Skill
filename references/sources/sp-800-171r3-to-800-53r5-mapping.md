# SP 800-171 Rev 3 → SP 800-53 Rev 5 Parent-Control Mapping (secondary lens)

**What this is.** For each active SP 800-171 **Rev 3** security requirement, the SP 800-53 **Rev 5** control(s) and enhancement(s) NIST links as its source. Rev 3 is **not** the CMMC Level 2 basis (that is Rev 2 — see `sp-800-171r2-to-800-53r4-mapping.md`), but it is a legitimate second lens on what a Rev 2 requirement is trying to accomplish: Rev 3 restated the same requirement family against the current SP 800-53 catalog.

**How to use it.** Rev 3 requirement `03.xx.xx` corresponds to Rev 2's `3.x.x` by sort-id (shown in the "(Rev 2)" column). **33 of Rev 2's 110 requirements were consolidated in Rev 3** and have no direct row here — for those, stay on the Rev 4 default. Read the control text in `references/sources/sp-800-53-rev5-cui-parents.md`.

**Source.** NIST's official OSCAL catalog for **SP 800-171 Rev 3** (`usnistgov/oscal-content`), following each requirement's `reference` links to SP 800-53 Rev 5 control identifiers. Withdrawn Rev 3 controls are omitted.

**Caveat.** This is a machine-derived mapping from NIST's Rev 3 OSCAL, not a NIST-published crosswalk table. It is reliable for *finding the parent control to interpret from*; it is not a compliance crosswalk between the two revisions.
